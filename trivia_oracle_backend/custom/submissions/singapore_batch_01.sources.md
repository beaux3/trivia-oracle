# Sources for singapore_batch_01

Verification standard for this batch: the requester asked for **one confirming source per fact**
(not the two independent sources CONTRIBUTING.md normally requires). Every URL below was opened
during research. Facts marked (1 source) were confirmed by that source only; where the sources
disagreed the clue was left out (Merlion relocation year, Sentosa renaming year, Clementi's
namesake, Jaywick ship count, anthem adoption date, Civilian War Memorial height, Sook Ching toll
is given as a range).
